# tiny-qsim
tiny-qsim is a library for simulating computation on a [quantum computer](https://en.wikipedia.org/wiki/Quantum_computing) using [quantum logic gates](https://en.wikipedia.org/wiki/Quantum_logic_gate). It can simulate phenomena like [entanglement](https://en.wikipedia.org/wiki/Quantum_entanglement) and [teleportation](https://quantum.cloud.ibm.com/learning/en/courses/basics-of-quantum-information/entanglement-in-action/quantum-teleportation), and run quantum algorithms such as [Grover’s algorithm](https://quantum.cloud.ibm.com/learning/en/courses/fundamentals-of-quantum-algorithms/grover-algorithm/grover-algorithm-description). Implementations of these examples are in the `examples` folder.
